Halaman khusus panitia. Menampilkan data peserta lengkap dengan foto, lembaga, dan kontak pembina dari file rekap JSON.

ℹ️ Cara pakai: Klik ＋ Pilih file rekap JSON → pilih file hasil ekspor dari halaman rekap.html (yang lengkap, bukan yang publik). Bisa pilih banyak file sekaligus. Data tidak diunggah ke server — semua diproses di browser.
Belum ada data. Silakan pilih file rekap JSON terlebih dahulu.
