Formulir Pendaftaran Madrasah

Satu formulir untuk satu madrasah, bisa mendaftar banyak cabang lomba sekaligus. Setiap cabang lomba punya pembina/pendamping sendiri. Hasilnya satu file JSON.

Mode offline: data tidak dikirim ke internet. Setelah formulir valid, klik Ekspor JSON dan serahkan file hasil unduhan kepada panitia. Satu file JSON bisa memuat lebih dari satu cabang lomba, masing-masing dengan pembina dan peserta sendiri.

01. Data madrasah

Informasi asal peserta dan kontak yang dapat dihubungi.

02. Cabang lomba yang diikuti

Tambahkan satu entri untuk setiap cabang lomba. Setiap cabang punya pembina dan daftar pesertanya sendiri.

Dokumen wajib per peserta: foto siswa (maks. 2 MB), ijazah jenjang sebelumnya (maks. 5 MB), dan Kartu Keluarga/KK (maks. 5 MB). Format foto: JPG/PNG; ijazah dan KK: JPG/PNG/PDF. Semua berkas akan disimpan di dalam satu file JSON, jadi semakin banyak lomba dan peserta, semakin besar file JSON.
Total lomba: 0 Total peserta: 0

03. Periksa dan ekspor

Pastikan data sudah benar sebelum menyimpan file pendaftaran.


        
Catatan: file JSON berisi data pribadi peserta. Simpan dan kirimkan hanya kepada panitia melalui jalur yang disepakati.
